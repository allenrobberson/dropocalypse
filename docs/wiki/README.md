# Wiki source

These files are the source of the [Dropocalypse wiki](https://github.com/allenrobberson/dropocalypse/wiki).
Each file is one wiki page (`Quick-Start.md` → the "Quick Start" page); `_Sidebar.md` and `_Footer.md`
appear on every page. Edit them here: the Wiki workflow (.github/workflows/wiki.yml) copies them to the wiki when they change on main.
