# Keyboard Shortcuts

| Key | Action |
|---|---|
| `F` | Full screen on / off |
| `T` or `S` | Show / hide the toolbar |
| `Esc` | Hide the toolbar; press again to exit full screen |
| `⌃⌘F` | Full screen (Mac menu shortcut; the green window button works too) |
| `F11` | Full screen (Windows) |
| `Ctrl+O` | Choose a logo (Windows) |
| `L` | Choose a logo |
| `G` | Show / hide the logo |
| `←` `→` | Previous / next style |
| `A` | Auto-cycle on / off |
| `D` | Detach / attach the controls window |
| `⇧⌘D` | Detach / attach the controls (Mac menu shortcut) |

On the Mac, the menu bar has the same actions: **File → Choose Logo… (⌘O)** and **Remove Logo**, and **Visualizer → Next Style (⌘→), Previous Style (⌘←), Full Screen (⌃⌘F), Show/Hide Toolbar (⌘,), Restart Audio**.

Shortcuts work whenever the Dropocalypse window is in front. Keys like ⌘ combinations are reserved for the Mac menus.
